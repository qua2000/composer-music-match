# Audio files to add

Place the verified, redistributable 60-second MP3 clips in this folder:

- `nachtmusik-60s.mp3`
- `turkish-march-60s.mp3`
- `piano-concerto-21-60s.mp3`
- `symphony-40-60s.mp3`

The app expects these exact filenames. No recordings are included because a work's public-domain status does not automatically clear the copyright in a particular performance/recording. Check that each source permits copying, trimming, and public redistribution in the countries relevant to the repository.
